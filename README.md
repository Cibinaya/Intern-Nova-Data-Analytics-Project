Pune Region School Analytics and Dashboard (2025-2026)

Project Overview:
This project presents a comprehensive Power BI analytics dashboard developed for the Pune Region school network. The primary objective is to evaluate school distribution, student enrollments, management types, and infrastructural patterns across various blocks to assist stakeholders in data-driven educational planning.

Problem Statement:
To analyze educational data across the Pune region to identify urban-rural disparities, student enrollment distributions, management-wise administrative control, and institutional drop-off rates, ultimately providing data-driven recommendations for resource allocation and educational policymaking.

Dataset Description:
The dataset contains regional educational metrics for the Pune region, including:

Block Information (blkname): Administrative blocks such as Haveli, Khed, Baramati, etc.

School Categories (schcat_desc): Primary, Upper Primary, Secondary, and Higher Secondary classifications.

Management Types (schmgt_desc): Local Body, Private, and other administrative frameworks.

Student Counts (Total_Students, Std_1 to Std_12): Grade-wise and cumulative enrollment data.

Tools Used:

Power BI: For dashboard design, data modeling, sparkline trend axes, and interactive visualizations.

Python / Pandas: Initial data inspection and formatting (where applicable).

GitHub: For project repository hosting and professional documentation.

Data Cleaning Process:

Inspected dataset for structural consistency, spelling variations in block names, and blank rows.

Handled missing values in auxiliary numerical columns using median imputation to prevent skewness.

Removed duplicate entries to ensure high data integrity before importing into Power BI.

Exploratory Data Analysis (EDA):

Descriptive Statistics: Highlighted wide variations in school sizes and student counts across blocks.

Correlation Analysis: Confirmed a strong positive relationship between institutional density and total student enrollment.

Outlier Identification: Boxplot analysis identified major urban blocks (like Haveli) as outliers with exceptionally high student volumes.
